# Auto Jump Script for Roblox

This script enables auto jumping for players in a Roblox game. When a player's character is added to the game, the script connects to the Humanoid's Jumping event and automatically triggers a jump.

## Installation

1. Open Roblox Studio.
2. Navigate to the `ServerScriptService` in the Explorer.
3. Right-click on `ServerScriptService` and select `Insert Object` > `Script`.
4. Name the script `AutoJumpScript`.
5. Copy and paste the contents of `AutoJumpScript.server.lua` into the script.

## Usage

- The script will automatically enable auto jumping for all players when the game starts.
- To disable auto jumping, simply remove the script from the `ServerScriptService`.
